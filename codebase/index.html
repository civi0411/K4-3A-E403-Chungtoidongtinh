🎓 BÀI LAB 3: CHATBOT VS REACT AGENT — TỪ LÝ THUYẾT ĐẾN THỰC THI

Trong kiến trúc AI hiện đại, các mô hình ngôn ngữ lớn (LLM) không chỉ dừng lại ở việc sinh văn bản đóng băng. Mô hình ReAct Agent kết hợp hai năng lực cốt lõi: Suy luận (Reasoning) và Hành động (Acting). Khi gặp một yêu cầu phức tạp, Agent sẽ tự động lập luận xem cần làm gì, phát lệnh gọi công cụ ngoại vi qua Native Tool Calling, nhận kết quả quan sát và tiếp tục vòng lặp cho đến khi giải xong bài toán.

💡
Mục tiêu đầu ra của Bài Lab:

Sau khi hoàn thành bài Lab 180 phút, học viên sẽ nộp một sản phẩm cá nhân hoàn chỉnh: mã nguồn Agent chạy mượt mà chu trình ReAct Loop ( Thought -> Action -> Observation ) qua Native Tool Calling, tự động thực thi công cụ và trích xuất file Waterfall Trace Log chuẩn hóa tại docs/trace_waterfall.json.

src/chatbot_vanilla.py Task 1.1 Baseline (Chatlog T10503) 
def call_anthropic(prompt: str, model: str = ANTHROPIC_MODEL, temperature: float = 0.7):
    # Cấu hình gọi API sinh văn bản cho Chatbot thông thường
    response = client.messages.create(
        model=model,
        temperature=temperature,
        messages=[{"role": "user", "content": prompt}]
    )
    return response.content[0].text

Mục 5 · Task 2.1 (40 phút)

🐍 TASK 2.1 — LẬP TRÌNH HÀM THỰC THI TOOL (PYTHON)

Khi model phát lệnh gọi tool, ứng dụng Python cần ánh xạ từ tên hàm (tool_name) sang hàm thực tế trong hệ điều hành, đồng thời bọc trong khối try...except để áp dụng cơ chế Self-healing loop nếu có lỗi xảy ra.

src/tool_executor.py Dispatcher & Error Handling 
def execute_tool(tool_name: str, tool_args: dict) -> str:
    """Hàm thực thi công cụ và bắt lỗi an toàn (Self-healing)"""
    try:
        if tool_name == "calculator":
            return str(eval(tool_args["expression"], {"__builtins__": None}, {}))
        elif tool_name == "query_database":
            return query_db_mock(tool_args["student_id"])
        else:
            return f"Lỗi: Không tìm thấy công cụ '{tool_name}'"
    except Exception as e:
        # Chuyển lỗi thành Observation text để LLM tự sửa sai
        return f"Lỗi thực thi công cụ: {str(e)}"
Mục 6 · Task 2.2 (50 phút)

🔄 TASK 2.2 — LẬP TRÌNH REACT LOOP VÀ ĐIỀU KIỆN DỪNG

Đây là linh hồn của toàn bộ bài Lab 3. Vòng lặp ReAct Loop chạy tuần tự qua 3 trạng thái:

  • 1. Thought: LLM suy luận bước giải quyết và quyết định xem có cần gọi Tool hay không.
  • 2. Action: Nếu LLM trả về stop_reason: tool_use, lấy arguments và chạy hàm execute_tool().
  • 3. Observation: Đóng gói kết quả thành message và gửi lại cho LLM.
🛑
Thiết lập điều kiện dừng (Stop Condition)

Để phòng tránh việc Agent rơi vào vòng lặp vô tận tốn credit API, bạn bắt buộc phải cấu hình biến trần max_iterations = 5. Vòng lặp sẽ dừng ngay khi model trả về văn bản thông thường (không còn lệnh gọi tool) hoặc khi chạm ngưỡng 5 lượt.

src/react_agent.py Core ReAct Loop Implementation 
def run_react_agent(user_query: str, max_iterations: int = 5):
    messages = [{"role": "user", "content": user_query}]
    iteration = 0

    while iteration < max_iterations:
        iteration += 1
        response = client.messages.create(
            model=ANTHROPIC_MODEL,
            max_tokens=1024,
            temperature=0.0, # Nhiệt độ 0.0 để output tất định
            tools=TOOLS,
            messages=messages
        )

        if response.stop_reason == "end_turn":
            # Model đã suy luận xong và trả lời người dùng
            return response.content[0].text

        if response.stop_reason == "tool_use":
            # Model yêu cầu gọi tool: Trích xuất tên tool và tham số
            tool_call = [b for b in response.content if b.type == "tool_use"][0]
            obs = execute_tool(tool_call.name, tool_call.input)
            
            # Gửi tiếp Observation vào chuỗi hội thoại
            messages.append({"role": "assistant", "content": response.content})
            messages.append({
                "role": "user",
                "content": [{
                    "type": "tool_result",
                    "tool_use_id": tool_call.id,
                    "content": str(obs)
                }]
            })

    return "Đã đạt ngưỡng 5 bước suy luận tối đa mà chưa hoàn tất."
